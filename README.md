## Weekly Projects

### **Week 1: Environment & Hello World**
- **Goal:** Set up development environment and build a simple HTML/CSS proof of concept.  
- **Folder:** `week-1-hello-world`  
- **Tech Stack:** HTML, CSS  
- **Highlights:** Basic webpage with semantic structure and styling.  

### **Week 2: Smart Study Session Tracker**
- **Goal:** Core logic implementation and timer-based application.  
- **Folder:** `week-2-study-tracker`  
- **Tech Stack:** HTML, CSS, JavaScript  
- **Highlights:** Tracks study sessions in real time (HH:MM:SS), clean UI, pause/reset features, dark mode.  

### **Week 3: Study Resources Explorer**
- **Goal:** Integrate external API to fetch and display data dynamically.  
- **Folder:** `week-3-study-resources`  
- **Tech Stack:** HTML, CSS, JavaScript, Open Library API  
- **Highlights:** Interactive UI, search and filter books, unique card design, user-friendly interface.  

### **Week 4: Optimization & Advanced Features**
- **Goal:** Improve performance, implement advanced front-end features, and optimize UI.  
- **Folder:** `week-4-optimization-dashboard`  
- **Tech Stack:** HTML, CSS, JavaScript  
- **Highlights:** Fast-loading interactive dashboard with live updates, better code readability, responsive design.  

### **Week 5: Production Readiness**
- **Goal:** Deploy a polished project to a live environment and ensure production quality.  
- **Folder:** `week-5-production-website`  
- **Tech Stack:** HTML, CSS, JavaScript, Netlify  
- **Highlights:** Fully deployed website, responsive design, interactive elements, polished UI/UX.  
- **Live Demo:** [Week 5 Project on Netlify](https://week-5-production-website.netlify.app)

### **Week 6: Capstone Dashboard**
- **Goal:** End-to-end implementation of a real-world dashboard with task, client, project, and payment management.  
- **Folder:** `week-6-capstone-dashboard`  
- **Tech Stack:** HTML, CSS, JavaScript, JSON (for backend data)  
- **Highlights:**  
  - Interactive dashboard with editable cards for clients, projects, and payments  
  - Task manager with priority, client/project selection, and payment tracking (Ksh)  
  - Dark mode with readable design  
  - Clean, unique UI with responsive layout
